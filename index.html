    연동 설정 방법 (최초 1회)
    1. 이 파일을 GitHub Pages 등 https:// 주소에 올립니다. (구글 로그인은 로컬 파일에서 동작하지 않습니다)
    2. console.cloud.google.com에서 프로젝트를 만들고, API 및 서비스 → 라이브러리에서 Google Calendar API를 사용 설정합니다.
    3. OAuth 동의 화면을 외부(External)로 만들고, 테스트 사용자에 본인 구글 계정을 추가합니다.
    4. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션을 만들고, 승인된 자바스크립트 원본에 이 페이지의 주소(예: https://아이디.github.io)를 넣습니다.
    5. 발급된 클라이언트 ID를 이 대시보드의 설정에 붙여넣고 저장한 뒤, 연결하기를 누릅니다.
